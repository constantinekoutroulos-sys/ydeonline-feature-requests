# ydeonline.gr: Αιτήματα χρηστών

Εδώ προτείνετε νέες λειτουργίες και βελτιώσεις για την εφαρμογή ΥΔΕ στο [ydeonline.gr](https://ydeonline.gr). Ο κώδικας της εφαρμογής δεν βρίσκεται εδώ.

## Πώς στέλνω αίτημα
1. Πατήστε **Issues** και μετά **New issue**.
2. Διαλέξτε **Αίτημα λειτουργίας** και συμπληρώστε τη φόρμα.
3. Πριν γράψετε, ψάξτε στα Issues μήπως το έχει ήδη ζητήσει κάποιος. Αν ναι, βάλτε 👍 στο υπάρχον.

Χρειάζεται δωρεάν λογαριασμός GitHub.

## Σημαντικό για τα προσωπικά δεδομένα
Τα αιτήματα είναι **δημόσια**. Μη γράφετε ονόματα, διευθύνσεις, αριθμούς παροχής, τηλέφωνα ή άλλα στοιχεία πελατών ή δικά σας. Σε screenshots κρύψτε ό,τι προσωπικό φαίνεται.

## Τι σημαίνουν τα labels
- **νέο**: μόλις ήρθε
- **υπό εξέταση**: το κοιτάζω
- **προγραμματίστηκε**: θα γίνει
- **έγινε**: είναι πια στην εφαρμογή
- **δεν θα γίνει**: δεν ταιριάζει στην εφαρμογή

Για προσωπικά θέματα ή λάθη στον λογαριασμό σας, γράψτε μέσα από το messenger της εφαρμογής ή στο constantine.koutroulos@gmail.com.
